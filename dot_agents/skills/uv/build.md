# Building Python packages with uv

## Select a backend deliberately

Use `uv_build` for a new pure-Python package. Preserve the backend in an existing project unless the user requests a migration. Packages with native extension modules need a backend that supports their build system, such as maturin, scikit-build-core, setuptools, or hatchling.

Generate a library with the installed uv so the `uv_build` requirement matches that uv release:

```bash
uv init --lib --build-backend uv package-name
```

On the current uv 0.12 series, the generated section resembles:

```toml
[build-system]
requires = ["uv_build>=0.12.3,<0.13.0"]
build-backend = "uv_build"
```

Do not copy that exact version range blindly after uv changes. Prefer the range generated by `uv init`, or update it with the same compatibility policy used by the project.

## Default layout

`uv_build` uses a `src` layout by default:

```text
pyproject.toml
src/
└── package_name/
    └── __init__.py
```

Distribution names normalize hyphens to underscores for import packages: `example-tools` normally maps to `example_tools`.

A minimal project includes project metadata and the generated build section:

```toml
[project]
name = "example-tools"
version = "0.1.0"
requires-python = ">=3.14"
dependencies = []

[build-system]
requires = ["uv_build>=0.12.3,<0.13.0"]
build-backend = "uv_build"
```

Honor the Python range required by the project rather than replacing it with the workstation's version.

## Module placement

Configure a module outside the default location only when the repository layout requires it:

```toml
[tool.uv.build-backend]
module-name = "example_tools"
module-root = ""
```

For a namespace package such as `company.tools`, place the import package at `src/company/tools/` and omit `src/company/__init__.py`:

```toml
[tool.uv.build-backend]
module-name = "company.tools"
```

## Included files

`uv_build` already excludes bytecode and cache files. Add source inclusion or exclusion rules narrowly:

```toml
[tool.uv.build-backend]
source-include = ["assets/**"]
source-exclude = ["/dist", "tests/**"]
```

Leading `/` anchors a pattern at the project root. Review the built source distribution and wheel before changing broad inclusion rules:

```bash
uv build
uvx twine check dist/*
```

Do not publish a build unless the user explicitly requests publication.
